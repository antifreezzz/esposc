# esposc: заметки для агента

Что это и как устроено - в `README.md`. Ручки BSP - в `README.md` и `docs/controls.html`.

## Правила проекта

- Разъём **USB** платы никогда не втыкать в ПК. Прошивка и лог только через COM: `/dev/ttyACM0`.
- TDD: хост-тест до кода, увидеть красный, потом зелёный. Тесты в `host/test_*.c`, свой мини-фреймворк `host/test.h`.
- Коммит каждой готовой единицы работы, git-личность `antifreezzz <me@kvatech.ru>`.
- Комментарии и доки по-русски, код и git по-английски, без длинных тире.
- Меняешь ручки, страницы или MIDI - обнови `README.md` (таблица ручек), `docs/controls.html`
  (массивы `PAGES`, `K303`, `MODELS` и тексты карточек) и спеку этапа.
- В рендере (всё, что зовётся из `acid_synth_render*`) никаких локов, аллокаций и логов.

## Как пользователь работает с BSP

- Смотрит на экран BSP: там значение энкодера 0..127. Маппинг должен совпадать с тем, что на экране:
  энкодер 1 значение N = страница N, значения вне диапазона игнорируются. Зоны хода и листание
  по направлению пользователь отверг.
- Щелчки энкодеров BSP чёткие, по 1 значению; при быстром вращении BSP пропускает значения (шаг 4 и больше).
- BSP помнит положение энкодеров между включениями.

## Команды

```sh
# хост-тесты
cmake -S host -B host/build && cmake --build host/build && ctest --test-dir host/build
# прошивка
. ~/esp/esp-idf-v6.1/export.sh && idf.py -p /dev/ttyACM0 flash
```

Лог без `idf.py monitor` (ему нужен tty): pyserial, `serial.Serial('/dev/ttyACM0', 115200)`,
читать строки в файл в фоне. Открытие порта может перезагрузить плату.

## Инварианты и как их проверять

- **Автопилот бит в бит как в `main`** при любых правках live-режима:
  ```sh
  git worktree add /tmp/esposc-main main
  cmake -S /tmp/esposc-main/host -B /tmp/esposc-main/host/build && cmake --build /tmp/esposc-main/host/build
  /tmp/esposc-main/host/build/acid_render /tmp/a.wav 130 && host/build/acid_render /tmp/b.wav 130
  cmp /tmp/a.wav /tmp/b.wav && git worktree remove --force /tmp/esposc-main
  ```
  Автопилот играет только слот 0 (303); выход слота 1 добавляется только если он `!= 0.0f` (иначе -0 меняет биты).
- Бюджет: блок 2000 мкс, синт 2 666 мкс на кусок. Худший случай - оба синта на modal (тип 21).
- Blob памяти ручек версионирован магией `BLOB_MAGIC` в `acid_synth.c`: меняешь раскладку
  `knob[][]` или число типов - подними версию, иначе старый blob из NVS применится криво.

## Грабли

- Plaits собирается с `-DTEST` (переносимый режим без ARM asm) и `-include stdio.h`; предупреждения вендорного кода глушатся `-w`.
- `git checkout <файл>` для отката мутации в тесте стирает и все незакоммиченные правки файла.
  Мутации откатывать точечно (sed, Edit) или сначала коммитить.
- Snap-chromium не пишет в `/tmp`: скриншот `--headless --screenshot=$HOME/x.png`, потом перенести.
- `idf.py` после правок `sdkconfig.defaults` их не подхватывает, если `sdkconfig` уже есть: править и его (он в .gitignore).
