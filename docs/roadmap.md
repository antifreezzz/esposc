# Дорожная карта

Записано 2026-10-30, после этапа 8 (стерео, демо-трек, мелочи этапа 7). Порядок проектов согласован,
по каждому перед работой - своя спека в `docs/superpowers/specs/`.

## Запас ресурсов сейчас

- Ядро 1 (синт 1, ударка, эффекты, микс): демо ~1540 мкс из 2000 на блок, худший случай (оба синта modal,
  все эффекты) ~1750 мкс. Ядро 0 (синт 2 и весь USB): до ~600 мкс из 666 на кусок.
- Внутренняя RAM ~100 КБ свободно, PSRAM ~1.7 МБ, флэш 8 МБ.
- Узкое место - кэш команд 32 КБ: новый код вытесняет горячий код Plaits и эффектов, горячее - в IRAM
  через `components/acid/linker.lf`.

## Проекты по порядку

### 1. Ударка: новые голоса синтезом

- Томы, римшот, ковбелл; ноты по разметке GM: томы 41, 43, 45, 47, 48, 50, римшот 37, ковбелл 56
  (крэш 49 и райд 51 - в проекте 2).
- Хэт глушит сам себя в обе стороны: закрытый обрывает открытый, удар по открытому обрывает закрытый
  (если не ресурсоёмко).
- Внятный лимит одновременно звучащих голосов: прошивка не должна захлебнуться. Играть «барабанщиком-пауком»
  не планируется, лимит в рамках разумного.
- Ручки ударки раскладываются на несколько страниц (страниц до 128, места хватает).

### 2. Тарелки на сэмплах

- Крэш и райд из нормальных сэмплов, слои по силе удара (velocity). Классический сэмплер не нужен:
  это проигрыватель сэмплов ударки.
- Сэмплы во флэше (8 МБ), оценка: крэш и райд по 3 слоя ~1-1.5 МБ. Откуда брать сэмплы
  (свои, бесплатная библиотека с понятной лицензией) - решить в спеке.

### 3. Второй 303

Две перекликающиеся кислотные линии; голос 303 дешёвый по ресурсам.

### 4. Арпеджиатор

Для эксперимента: арпеджиатор есть в BSP и большинстве контроллеров, ценность проверить на слух.

## Позже, когда будет электроника

- Звук на I2S ЦАП PCM5102 вместо USB-аудиоинтерфейса: ради компактности и надёжности (без потери звука
  на старте и ошибок передачи), ресурса освободит немного, в основном на ядре 0.
- MIDI по DIN (оптопара на UART) вместо USB: вместе с I2S уберёт USB из прошивки целиком.
- Оптимизация кода - после того, как устаканится обвязка (размер блока и буферы поменяются). До тех пор
  держать бенч худшего случая, чтобы новые фичи не съели запас незаметно.

## Решено не делать

- Ревёрб на плате: есть хороший в рекордере (Tascam Portacapture X8).
- Классический сэмплер: 2 МБ PSRAM для чего-то нормального мало.
- Векторные инструкции ESP32-S3 (PIE): только целочисленные, а звук во float; держать в запасе на крайний случай.
- Случайное время дилэя: отложено.
