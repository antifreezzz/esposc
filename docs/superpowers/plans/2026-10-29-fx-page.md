# FX Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** страница 4 с хрустом, дилэем и статтером по темпу MIDI clock, доработки пампинга.

**Architecture:** DSP-блоки в `acid_fx.c` (как пампинг и DJ-фильтр), темп в `acid_clock.c`, разбор клока
в `acid_midi.c`, страница и микс в `acid_synth.c`. Нейтраль - прежний путь микса.

**Tech Stack:** C11, ESP-IDF v6.1, хост-тесты `host/test.h`.

**Spec:** `docs/superpowers/specs/2026-10-29-fx-page-design.md`

## Global Constraints

- Комментарии по-русски, код и git по-английски, без длинных тире. TDD: красный, потом зелёный.
- Автопилот бит в бит как в `main`. В рендере и CC без локов, аллокаций, логов.
- Буферы: дилэй 36 000 сэмплов int16, статтер 24 000 сэмплов int16, масштаб записи 16384 (запас +-2).
- Темп 60..200 BPM, с нуля 120. Доли дилэя 1/16, 1/8, 3/16, 1/4, 3/8. Доли статтера 1/4, 1/8, 1/16, 1/32.
- Зоны ручки: `зона = v * N / 128` (как тип на энкодере 2). У статтера 0 - выкл, остальное 4 зоны по 1..127.

## Review Focus

1. Включили дилэй, выключили, хвост затих, снова включили: старые повторы не всплывают (`test_delay_no_stale_tail`).
2. Смена времени дилэя на ходу без щелчка (`test_delay_time_change_smooth`).
3. Статтер: включение, шов петли и выключение без щелчка (`test_stutter_click_free`).
4. Клок пропал посреди игры: темп остаётся последним (`test_clock_keeps_tempo_without_ticks`).
5. Время дилэя длиннее буфера при медленном темпе: делится пополам, не читает за край (`test_delay_long_time_fits`).

### Task 1: MIDI clock and tempo

**Files:** `components/acid/acid_midi.c`, `include/acid_midi.h` (типы `ACID_MIDI_CLOCK`, `ACID_MIDI_START`,
`ACID_MIDI_CONTINUE`); create `components/acid/acid_clock.c`, `include/acid_clock.h`; tests `host/test_midi.c`, `host/test_clock.c`.

**Produces:**
```c
typedef struct { float sr; uint32_t last; int have_last; float spb; float acc; int n; } acid_clock_t;
void acid_clock_init(acid_clock_t *c, float sr);           // spb = 120 BPM
void acid_clock_tick(acid_clock_t *c, uint32_t now);        // now - сэмплы с начала
float acid_clock_spb(const acid_clock_t *c);                // сэмплов на четверть
```
- [ ] Тесты: парсер даёт CLOCK/START/CONTINUE из CIN 0xF с 0xF8/0xFA/0xFB; тики каждые 1000 сэмплов -> spb 24000 +/- 1;
  тики с джиттером +-16 сэмплов -> spb в 1%; темп вне 60..200 обрезается; пауза 5 с без тиков, затем тик - spb прежний
  (`test_clock_keeps_tempo_without_ticks`, интервал больше 4 нормальных отбрасывается).
- [ ] RED, реализация, GREEN, commit `feat(acid): MIDI clock tempo tracking`.
