# Cymbals Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** крэш 49, райд 51 и купол райда 53 из многослойных сэмплов во флэше, страница 2 «ударка 2», остальные страницы +1.

**Architecture:** образ набора (`acid_bank`: заголовок, таблицы нот/слоёв/повторов, IMA ADPCM стерео блоками) собирает
`tools/samples/build_samples.py`; прошивка отображает раздел `samples` через `esp_partition_mmap`, хост читает файл.
Голоса тарелок (`acid_cym`) декодируют ADPCM на лету и отдают стерео в микс синта рядом с хэтами.

**Tech Stack:** C11, ESP-IDF v6.1, хост-тесты `host/test.h`; Python 3 + numpy + ffmpeg, `unittest`.

**Spec:** `docs/superpowers/specs/2026-10-30-cymbals-design.md`

## Global Constraints

- Комментарии и доки по-русски, код и git по-английски, без длинных тире. TDD: красный, потом зелёный. Коммит на задачу.
- В рендере (всё из `acid_synth_render*`, значит и `acid_cym_*_next`) без локов, аллокаций, логов.
- Ноты на канале ударки (`ch = 1`): крэш 49, райд 51, купол 53. Остальные ноты набора игнорируются.
- Образ: ADPCM 4 бита, стерео, 48000 Гц. Голосов 6. Повторный удар той же ноты: прежний голос уходит ~50 мс; забор голоса ~5 мс.
- Ручки страницы 2 (энкодер: что): 2 крэш громкость, 3 крэш хвост, 4 крэш строй, 5 крэш панорама, 6 райд громкость,
  7 райд хвост, 8 райд строй, 9 райд панорама, 10 купол громкость, 11 чувствительность. 12-16 свободны.
- Строй: `2^(п/12)`, п = (v - 64) / 63 × 12, v 0 зажимается до -12. Хвост: 127 естественный, 0 спад ~0.15 с.
  Чувствительность: `e = 1 - sens * (1 - vel)`, громкость удара `e*e`, после включения 100. Панорама - баланс по закону этапа 8 (`acid_pan`), 64 как в записи.
- Страницы: 0 микс, 1 ударка, 2 ударка 2, 3 синт 1, 4 синт 2, 5 эффекты, 6 тональность; > 6 игнор; после включения 3.
- `BLOB_MAGIC` не меняется (ручки ударки в blob не входят). Демо бит в бит как в `main` после задачи 1.
- Разделы: nvs 0x9000 24K, phy_init 0xf000 4K (как сейчас), factory 0x10000 2M, `samples` data/0x40 0x210000 до конца 8 МБ (0x5F0000).
- Библиотека и образ в git не кладутся. Атрибуция в README: «Тарелки: Naked Drums, Wilkinson Audio, CC-BY 4.0».

### Task 2: Bank image and ADPCM decoder

**Files:** create `components/acid/include/acid_bank.h`, `components/acid/acid_bank.c`, `host/bank_fixture.c`, `host/bank_fixture.h`, `host/test_bank.c`;
`host/CMakeLists.txt` (fixture во все тесты и в `acid_render`), `components/acid/CMakeLists.txt`.

**Produces (`acid_bank.h`):**
```c
#define ACID_BANK_MAGIC 0x4B4E4241u // "ABNK"
#define ACID_BANK_VERSION 1
#define ACID_BANK_BLOCK 256         // кадров в блоке ADPCM
// Всё little-endian, смещения от начала образа. Порядок: заголовок, notes[], layers[], rrs[], данные (выровнены на 4).
typedef struct { uint32_t magic, version, size, crc32, rate; uint16_t nnotes, nlayers, nrr, pad; } acid_bank_hdr_t; // 28 байт
typedef struct { uint8_t note, nlayers; uint16_t first_layer; } acid_bank_note_t;  // слои по возрастанию vel_hi
typedef struct { uint8_t vel_hi, nrr; uint16_t first_rr; } acid_bank_layer_t;      // vel_hi 1..127
typedef struct { uint32_t offset, frames; } acid_bank_rr_t;
// Блок: L int16 pred, uint8 index, uint8 0, R то же (8 байт) - состояние ДО блока; дальше байт на кадр:
// младший полубайт L, старший R. Последний блок короче. Блоков ceil(frames / 256).
typedef struct { const uint8_t *img; const acid_bank_hdr_t *hdr; const acid_bank_note_t *notes;
                 const acid_bank_layer_t *layers; const acid_bank_rr_t *rrs; } acid_bank_t;
int acid_bank_open(acid_bank_t *b, const void *img, size_t len); // 1 - годен; CRC32 IEEE (как zlib) по [28, size)
const acid_bank_note_t *acid_bank_note(const acid_bank_t *b, int note); // NULL - нет ноты
typedef struct { int16_t pred; uint8_t index; } acid_adpcm_t;
int16_t acid_adpcm_step(acid_adpcm_t *st, uint8_t nibble); // стандартный IMA
```
`acid_bank_open` проверяет: магию, версию, `size <= len`, CRC, `rate == 48000`, что таблицы и все блоки всех повторов внутри `size`, `first_* + n <= count`.

**Produces (`bank_fixture.h`, только хост):**
```c
typedef struct { int note; int nlayers; int vel_hi[5]; int nrr[5]; int frames; } fixture_note_t;
// Собирает образ в buf: у повтора r слоя l ноты n сигнал - синус (n, l, r различимы по частоте и уровню),
// уровень слоя растёт с l. Возврат - размер. Внутри свой IMA-кодер.
size_t fixture_bank(uint8_t *buf, size_t cap, const fixture_note_t *notes, int n);
```
