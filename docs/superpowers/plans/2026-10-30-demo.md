# Demo Track Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** демо-трек вместо автопилота: партитура шлёт в синт MIDI как BSP, охват всех фич, вариации по кругам, смоук-тесты.

**Architecture:** модуль `acid_demo` (плеер, без знания о синте) выдаёт события `acid_midi_event_t` на кусок 32 сэмпла;
`main.c` и `acid_render` подают их в `acid_synth_midi` перед рендером куска. Песня - данные в `acid_demo_song.c`.
Старый автопилот (секвенсор, аранжировка, мутации, моно-ветка) удаляется, синт всегда от MIDI.

**Tech Stack:** C11, ESP-IDF v6.1, хост-тесты `host/test.h`.

**Spec:** `docs/superpowers/specs/2026-10-30-demo-design.md`

## Global Constraints

- Комментарии по-русски, код и git по-английски, без длинных тире. TDD: красный, потом зелёный.
- 125 BPM: тик клока 960 сэмплов (30 кусков по 32), шестнадцатая 5760 сэмплов. Темп не меняется.
- Каналы: ударка 2 (`ch = 1`), синт 1 5 (`ch = 4`), синт 2 6 (`ch = 5`). Ноты ударки: 36 бочка, 38 малый, 39 клэп, 42 закрытый, 46 открытый.
- Ручки только как CC страница (CC 10) + CC энкодера (`ENC_CC` в `acid_synth.c`), значения целые 0..127 по экрану BSP.
- Круг 0 канонический, вариации с круга 1, детерминированы номером круга.
- Демо не пишет во flash; без локов, аллокаций, логов в выдаче событий и рендере.

## Review Focus

1. BSP подключили посреди ноты демо: нет зависших нот и щелчка, после сброса ручки пользователя (проверка на плате + тест `test_demo_reset_clean`).
2. Стык круга: последняя нота круга не висит в следующем, Start на стыке не ломает квадрат тональности (`test_demo_loop_seam`).
3. Вариации не выходят за рамки: модели из пула части, ступени из набора, значения CC в 0..127 (`test_demo_vary_bounds`).
4. Смена типа синта 2 во время звучащей ноты - через штатный кроссфейд, без тишины дольше 20 мс (покрыто смоуком тишины).
5. Длинный прогон (3 круга) без NaN и без роста нагрузки (смоук и лог платы за круг).

### Task 1: Demo player

**Files:** create `components/acid/acid_demo.c`, `components/acid/include/acid_demo.h`, `host/test_demo.c`; add to `components/acid/CMakeLists.txt`.

**Produces:**
```c
#define ACID_DEMO_CHUNK 32
typedef struct { uint8_t note, vel, len; } acid_demo_note_t;      // len в шестнадцатых; 0 - пауза; len > 1 и
                                                                   // нота на следующем шаге до off - слайд (перекрытие)
typedef struct { uint8_t page, enc, from, to; } acid_demo_knob_t; // enc с 1 как на BSP; from == to - разово в начале части
typedef struct {
    uint8_t bars;
    const acid_demo_note_t *syn1, *syn2;  // 16 шагов, повтор каждый такт; NULL - молчит
    const uint8_t *drums;                 // 16 шагов, биты ACID_DEMO_KICK..OHAT; NULL - молчит
    const acid_demo_knob_t *knobs; uint8_t nknobs; // ручки плавно от from к to за часть (CC при смене целого)
    const uint8_t *syn2_pool; uint8_t npool; // модели синта 2 для вариаций; круг 0 - pool[0]
} acid_demo_part_t;
typedef struct { const acid_demo_part_t *parts; int nparts; } acid_demo_song_t;
typedef struct { /* позиция, круг, rng, звучащие ноты */ } acid_demo_t;
void acid_demo_init(acid_demo_t *d, const acid_demo_song_t *song);
int acid_demo_events(acid_demo_t *d, acid_midi_event_t *out, int cap); // события на следующий кусок, возврат - число
int acid_demo_cycle(const acid_demo_t *d);
```
Порядок событий куска: Start (начало круга), CC, note off, note on, клок. В конце круга все звучащие ноты off.

- [ ] Тесты на маленькой песне из теста: `test_demo_clock_every_960` (тик ровно на кусках 0, 30, 60...),
  `test_demo_start_at_loop` (0xFA в первом куске каждого круга), `test_demo_note_on_step` (нота синта 1 шага 2 на куске 360),
  `test_demo_slide_overlap` (len 2: on следующей ноты раньше off предыдущей), `test_demo_knob_ramp` (from 0 to 127 за часть:

  (круги 1..20: модель синта 2 из pool, круг 0 = pool[0]), `test_demo_deterministic` (два плеера, круг 3 - одинаковые события).
