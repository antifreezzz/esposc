# BeatStep Pro USB-MIDI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** BSP через хаб играет бас и барабаны синта на ESP и крутит его параметры; без BSP играет автопилот.

**Architecture:** Чистый C-парсер USB-MIDI в `components/acid`, live-режим в `acid_synth` (стек нот, CC-параметры),
USB-хост клиент в `main/` кладёт события в очередь FreeRTOS, synth_task применяет их между кусками по 32 сэмпла.

**Tech Stack:** C11, ESP-IDF v6.1 usb host, host-тесты CMake/ctest с `host/test.h`.

**Spec:** `docs/superpowers/specs/2026-10-28-bsp-midi-design.md`

## Global Constraints

- Комментарии и доки на русском, код и git на английском, без длинных тире.
- TDD: тест до кода. Хост-тесты: `cmake -S host -B host/build && cmake --build host/build && ctest --test-dir host/build`.
- Без BSP поведение автопилота как в stage 2 (все существующие тесты зелёные без правок ожиданий).
- В рендере никаких локов и аллокаций.

## Review Focus

1. Залипание: note on без note off, затем Stop или выдёргивание - тишина (`test_live_stop_silences`).
2. Перекрытие нот: вторая note on до note off первой - глайд без перезапуска огибающей (`test_live_overlap_slides`).
3. Отпускание верхней ноты при удержанной нижней - возврат к нижней, гейт держится (`test_live_release_returns_to_held`).
4. Пакеты USB-MIDI с нулевым паддингом и несколько событий в одном трансфере (`test_midi_parse_multi_and_padding`).
5. Переход live -> автопилот начинает трек с такта 0 и звучит как обычно (`test_live_off_restarts_track`).

typedef enum { ACID_MIDI_NOTE_ON, ACID_MIDI_NOTE_OFF, ACID_MIDI_CC, ACID_MIDI_STOP } acid_midi_type_t;
typedef struct { uint8_t type, ch, d1, d2; } acid_midi_event_t; // ch 0..15
int acid_midi_parse(const uint8_t *buf, size_t len, acid_midi_event_t *out, int max); // число событий

### Task 2: Live mode in synth

**Files:** Modify `acid_synth.{h,c}`; create `host/test_live.c`.

**Interfaces - Produces:**
```c
void acid_synth_set_live(acid_synth_t *s, int on); // 1: секвенсор молчит, ждём MIDI; 0: автопилот с такта 0
void acid_synth_midi(acid_synth_t *s, const acid_midi_event_t *ev);
```
Каналы: ch 4 (MIDI 5) ноты баса, ch 1 (MIDI 2) ноты барабанов, CC с любого канала, STOP глушит.
Параметры микса (бас, бочка, хэт, клэп, drive, мастер, база среза, res, env, decay, accent) становятся полями
со стартовыми значениями stage 2; автопилот читает те же поля. Accent: velocity > 100, decay accent = decay/2,
env accent = env * 5/3. Стек до 8 нот, приоритет последней.

- [ ] Тесты: `test_live_silent_until_note` (RMS ~0 после set_live 1);
  `test_live_note_pitch` (note 45 -> 110 Гц);
  `test_live_overlap_slides` (вторая нота: огибающая фильтра не перезапущена, высота ползёт к цели);
  `test_live_release_returns_to_held`;
  `test_live_note_off_closes_gate`;
  `test_live_accent_velocity` (vel 127 громче vel 100);
  `test_live_drums` (36 -> бочка, 39 -> клэп, 42 -> хэт, 46 -> открытый; vel 64 тише 127);
  `test_live_cc_params` (CC74 0 -> res 0, 127 -> 0.97; CC10 0/127 -> база 60/3000; CC93 -> wave);
  `test_live_stop_silences`; `test_live_off_restarts_track`; канал 6 и 10 игнорируются.
- [ ] RED, реализация, GREEN, весь suite зелёный, commit `feat(acid): live mode driven by MIDI events`.
