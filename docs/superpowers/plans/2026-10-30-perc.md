# Percussion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** томы 41-50, римшот 37 и ковбелл 56 синтезом, пять моделей на ручке, страницы 3-5 «томы», «рим», «ковбелл», остальные страницы +3.

**Architecture:** один модуль `acid_perc`: три инструмента (набор параметров из ручек) и пул голосов. Голос - два генератора,
шум, огибающие громкости и высоты, 4 полосовых резонатора и грязь (перегруз, крашер); модель переключает соединение.
Рендер кусками голос за голосом в стерео-буферы, микс синта добавляет их под пампинг и в `send_drums`, как тарелки.

**Tech Stack:** C11, ESP-IDF v6.1, хост-тесты `host/test.h`.

**Spec:** `docs/superpowers/specs/2026-10-30-perc-design.md`

## Global Constraints

- Комментарии и доки по-русски, код и git по-английски, без длинных тире. TDD: красный, потом зелёный. Коммит на задачу.
- В рендере (всё из `acid_synth_render*`, значит и `acid_perc_render`) без локов, аллокаций, логов.
- Ноты канала ударки (`ch = 1`): томы 41, 43, 45, 47, 48, 50 (индекс 0..5), римшот 37, ковбелл 56.
- Модели по числу на экране: 0 аналог, 1 квадраты, 2 FM, 3 модальный, 4 шум; больше 4 - игнор.
- Звучащих голосов перкуссии не больше 3; `hard_cuts` всегда 0. Повторный удар той же ноты - прежний уходит ~20 мс; забор ~5 мс.
- Velocity: `v = DRUM_VEL_FLOOR + (1 - DRUM_VEL_FLOOR) * vel / 127`, громкость `g = 1 - sens * (1 - v)`.
- Ручки трёх страниц (энкодер: что): 2 модель, 3 строй, 4 спад, 5 глубина высоты, 6 время высоты, 7 тон, 8 характер,
  9 щелчок, 10 перегруз, 11 крашер, 12 громкость, 13 панорама, 14 чувствительность, 15 интервал (томы), 16 ширина (томы).
- Диапазоны: строй томов ~40..250 Гц, рим и ковбелл ~200..2000, экспонентой; спад ~0.02..2 с; глубина 0..+36 полутонов;
  время высоты ~2..300 мс; интервал 0..12 полутонов; строй тома `i`: `строй * 2^(i * интервал / 12)`.
- Страницы: 0 микс, 1 ударка, 2 ударка 2, 3 томы, 4 рим, 5 ковбелл, 6 синт 1, 7 синт 2, 8 эффекты, 9 тональность; > 9 игнор; после включения 6.
- `BLOB_MAGIC` не меняется. Демо бит в бит как в `main` после задачи 1.
- Хэт не меняется (глушение в обе стороны уже есть), только тест.

## Review Focus

1. Строй и глубина высоты на максимуме у верхнего тома (250 Гц × 2^5 × 2^3 выше Найквиста): частоты генераторов и резонаторов
   зажаты ниже ~0.45 sr, резонаторы устойчивы (`test_perc_extreme_pitch_stable`, Task 2).
2. Смена модели или любой ручки, пока голос звучит: без NaN, взрыва и щелчка больше удара (`test_perc_knobs_while_ringing`, Task 2).
3. Самый тихий удар пэда (vel 1) при чувствительности 127 слышен, как у остальной ударки (`test_perc_soft_hit_audible`, Task 2).
4. Переключение демо и BSP (`acid_synth_init`) при звучащей дроби: голоса пустые, ручки по умолчанию (`test_live_perc_init_clears`, Task 4).
5. Молчащая перкуссия не стоит процессора: после затухания слоты свободны (`acid_perc_voices == 0`), рендер пропускает их (`test_perc_models_sound_and_end`, Task 2).

### Task 2: Percussion voice and instruments

**Files:** create `components/acid/include/acid_perc.h`, `components/acid/acid_perc.c`, `host/test_perc.c`; `components/acid/CMakeLists.txt` (SRCS).

**Produces (`acid_perc.h`):**
```c
enum { ACID_PERC_TOMS, ACID_PERC_RIM, ACID_PERC_COW, ACID_PERC_N };
enum { ACID_PERC_ANALOG, ACID_PERC_SQUARES, ACID_PERC_FM, ACID_PERC_MODAL, ACID_PERC_NOISE, ACID_PERC_MODELS };
// Ручка = энкодер - 2 (энкодер 2 -> 0).
enum { ACID_PERC_MODEL, ACID_PERC_TUNE, ACID_PERC_DECAY, ACID_PERC_PDEPTH, ACID_PERC_PTIME, ACID_PERC_TONE,
       ACID_PERC_CHAR, ACID_PERC_CLICK, ACID_PERC_DRIVE, ACID_PERC_CRUSH, ACID_PERC_LEVEL, ACID_PERC_PAN,
       ACID_PERC_SENS, ACID_PERC_INTERVAL, ACID_PERC_WIDTH, ACID_PERC_KNOBS };
#define ACID_PERC_SOUNDING 3
typedef struct { uint8_t knob[ACID_PERC_KNOBS]; /* сырые ручки */ int model; /* + производные параметры */ } acid_perc_inst_t;
typedef struct { /* исполнителю */ } acid_perc_voice_t;
typedef struct { acid_perc_inst_t inst[ACID_PERC_N]; acid_perc_voice_t v[ACID_PERC_SLOTS]; float sr; uint32_t hard_cuts; } acid_perc_t;
void acid_perc_init(acid_perc_t *p, float sr);              // ручки по умолчанию, голоса пустые
void acid_perc_set(acid_perc_t *p, int inst, int knob, int v); // v - число на экране; модель > 4 игнор; ручки 13-14 у рима и ковбелла игнор
int acid_perc_inst_of(int note, int *tom);                  // -1 не перкуссия; tom - индекс тома 0..5 или -1
void acid_perc_trigger(acid_perc_t *p, int note, float v);  // v 0..1 уже с полом ударки; не перкуссия - ничего
void acid_perc_render(acid_perc_t *p, float *l, float *r, int n); // перезаписывает l, r; голос за голосом
int acid_perc_voices(const acid_perc_t *p);   // занятые слоты
int acid_perc_sounding(const acid_perc_t *p); // занятые и не уходящие
```
Ручки действуют и на звучащие голоса (пересчёт раз в кусок рендера). Число слотов `ACID_PERC_SLOTS` (больше 3) и политика забора как у тарелок: после удара
звучащих не больше 3, лишний самый тихий уходит за ~5 мс, повторная нота - за ~20 мс. Умолчания из спеки (томы: модель 0, ~80 Гц, интервал ~3.5;
рим: модель 0, короткий, высокий, сильный щелчок; ковбелл: модель 1, ~540 Гц, отношение ~1.48); громкость 64-127 подбирается в Task 4.
