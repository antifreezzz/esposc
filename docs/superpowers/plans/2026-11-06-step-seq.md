# Встроенный секвенсер синтов: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** По секвенсеру на синт 1 и синт 2: такты рисуются пальцем на панели, песня собирается из тактов
с повторами, играет синт по тику клока, данные во flash синта, новый режим СЕКВ без BSP.

**Architecture:** Логика секвенсера (такты, песня, ход, ноты, blob, внутренний клок) - чистый C в
`components/acid/acid_seq.c`, живёт вне `acid_synth_t` и подключается к синту указателем (как `acid_link_use_custom`).
Синт зовёт его на каждом тике `ACID_MIDI_CLOCK` в фазе событий. Панель: геометрия и жест в
`components/panel_link/pl_seq_ui.c` (тесты на ПК), экран `panel/main/ui_seq.c`, новые кадры UART.

**Tech Stack:** C11, ESP-IDF 6.1, LVGL (панель), хост-тесты `host/test.h` + CMake/ctest.

**Spec:** `docs/superpowers/specs/2026-11-06-step-seq-design.md`

## Review Focus

1. Тональность сменилась, пока нота секвенсера звучит: note off должен уйти той же MIDI-ноте, что note on
   (тест в задаче 2).

5. Stop от BSP, потом ▶ с панели при стоящем `acid_beat`: секвенсер играет по внутреннему клоку (тест в задаче 4).

```c
#define ACID_SEQ_SYNTHS 2
#define ACID_SEQ_PATS 8
#define ACID_SEQ_STEPS 16
#define ACID_SEQ_ROWS 8
#define ACID_SEQ_CELLS 8
#define ACID_SEQ_REST 0x0F   // ступень паузы
#define ACID_SEQ_DEG 0x0F    // маска ступени 0..14
#define ACID_SEQ_ACC 0x10
#define ACID_SEQ_SLIDE 0x20
#define ACID_SEQ_EMPTY 0xFF  // пустая ячейка песни
#define ACID_SEQ_BPM_MIN 60
#define ACID_SEQ_BPM_MAX 200

typedef struct {
    uint8_t pat[ACID_SEQ_PATS][ACID_SEQ_STEPS];
    int8_t oct[ACID_SEQ_PATS];
    uint8_t cell[ACID_SEQ_ROWS][ACID_SEQ_CELLS], rep[ACID_SEQ_ROWS];
    uint8_t run, edit;            // edit - такт на экране, играет при пустой песне
    // позиция
    uint8_t row, n, c, step, tick, cur_pat; // строка, проход строки (0..rep-1), ячейка, шаг, тик в шаге
    int8_t sounding;              // звучащая MIDI-нота, -1 нет
    uint8_t armed;                // ждём шаг 0 общего такта
} acid_seq_track_t;

typedef struct {
    acid_seq_track_t t[ACID_SEQ_SYNTHS];
    uint8_t bpm;
} acid_seq_t;

typedef struct { uint8_t synth, on, note, vel; } acid_seq_ev_t;

void acid_seq_init(acid_seq_t *q);   // всё пусто (пауза), rep = 1, ячейки EMPTY, bpm 120, run 0
void acid_seq_set_step(acid_seq_t *q, int synth, int pat, int step, uint8_t v);
void acid_seq_set_oct(acid_seq_t *q, int synth, int pat, int oct);         // -2..+2, вне - игнор
void acid_seq_set_row(acid_seq_t *q, int synth, int row, const uint8_t cells[8], int rep); // rep 1..16
void acid_seq_set_edit(acid_seq_t *q, int synth, int pat);
void acid_seq_set_bpm(acid_seq_t *q, int bpm);                              // 60..200, вне - игнор
// ▶/■. Пуск: песня в начало; beat_running - ждать шага 0 общего такта. Стоп - note off звучащей в out.
int acid_seq_run(acid_seq_t *q, int synth, int on, int beat_running, acid_seq_ev_t out[2]);
// Тик клока. beat_step - шаг общего такта, начавшийся на этом тике (0..15), иначе -1.
// tonal - для ступени -> ноты. Возвращает число событий в out (не больше 4: по off и on на синт).
int acid_seq_clock(acid_seq_t *q, int beat_step, const acid_tonal_t *tonal, acid_seq_ev_t out[4]);
void acid_seq_rewind(acid_seq_t *q);  // START BSP и смена режима: позиции в начало (run не трогает)
```

Правила хода (из спеки): ячейки строки по порядку, пустые пропускаются; строка играется `rep` раз; пустая строка
пропускается; песня по кругу; вся песня пустая - играет `edit`. Шаг: ступень `ACID_SEQ_REST` - ничего не шлёт
(и гасит звучащую на своём тике 0). Нота = `acid_tonal_degree_note(tonal, base + 12*oct, deg)`,
`base` = 36 + тоника для синта 0, 48 + тоника для синта 1 (`tonal->tonic`). Гейт: off на тике 3, если у шага
нет `ACID_SEQ_SLIDE`; со слайдом звучащая не гасится, on следующей идёт раньше off прежней (off в том же вызове после on).
Правка строки или такта, которая сейчас играет: позицию прижать к границам на следующем тике, не сбрасывать.
