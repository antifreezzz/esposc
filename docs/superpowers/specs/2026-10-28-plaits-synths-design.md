# Stage 5: два синта со сменой типа синтеза, 303 и Plaits

## Зачем

Сейчас у BSP один бас-голос 303 на SEQ1, SEQ2 молчит. Хочется два независимых синта на SEQ1 и SEQ2,
у каждого тип синтеза выбирается ручкой на лету. Источник типов: наш 303 и порт Plaits
(Mutable Instruments, код MIT), в нём 24 модели, включая FM 2-op и 6-op (DX7).

## Цели

- Синт 1 играет SEQ1 (MIDI канал 5), синт 2 играет SEQ2 (канал 6). Звук полностью независимый.
- Тип синтеза у каждого синта: 0 - наш 303, 1..24 - модели Plaits в порядке движков Plaits 1.2.
- Смена типа на лету, без щелчка.
- Ручки каждого типа каждого синта помнятся в RAM: ушёл на другой тип и вернулся - звук прежний.
- Во flash пишем при смене типа, только если ручки этого типа менялись. При включении всё восстанавливается.
- Моно, приоритет последней ноты, слайд по перекрытию нот, accent по velocity > 100 - как у баса stage 3.
- Без BSP автопилот звучит бит в бит как в stage 4.

## Не цели

- Полифония (секвенсоры BSP одноголосые).
- Свои эффекты, модуляция LFO, MIDI clock.
- Soft takeover энкодеров.
- Пользовательские банки DX7 и wavetable (берём встроенные в Plaits).

## Анти-цели

- Щелчки при смене типа, при ретриггере нот, при записи во flash.
- Underrun'ы из-за нагрузки двух тяжёлых моделей.

## Что измерено пробой

- Plaits на ESP32-S3 240 МГц, один голос: 6-31% одного ядра в среднем, худший блок 12 сэмплов до 0.7 мс.
  Тяжелее всех modal (31%), аналоговые и аддитивный (~28%).
- Сейчас прошивка на 160 МГц, рендер 303 + ударки ~0.8 мс из 2 мс.
- Щелчки DX7 (модели 2, 3): движок на каждой ноте сбрасывает фазу операторов голоса, который ещё
  звучит хвостом (голосов два, по очереди). Правим в своей копии: фазу сбрасываем только у молчащего голоса.
- Chiptune (модель 7) без своей огибающей звучит меандром без затухания: включаем её огибающую.

## Решения

### Страницы (энкодер 1: щелчок - страница, по кругу)

0 - микс, 1 - ударка, 2 - синт 1, 3 - синт 2. До касания энкодера 1 - синт 1.

Микс, энкодеры 2-9: мастер, drive, синт 1, синт 2, бочка, хэты, клэп, малый.
Ударка - как в stage 4.

Страница синта, энкодер 2 - тип (0..24, зоны хода по 128/25). Остальное зависит от типа:

| Энк. | 303 | Plaits |
|---|---|---|
| 3 | cutoff | harmonics |
| 4 | resonance | timbre |
| 5 | env mod | morph |
| 6 | decay | затухание (decay) |
| 7 | accent | окраска LPG |
| 8 | пила/меандр | glide |
| 9 | glide | транспонирование ±12 |
| 10 | транспонирование ±12 | огибающая -> timbre, -1..1 |
| 11 | | огибающая -> morph, -1..1 |
| 12 | | огибающая -> высота, -1..1 |
| 13 | | сила accent |

### Plaits как голос

- LPG работает в режиме гейта: уровень = гейт ноты (держится, пока нота нажата), затухание - хвост
  после отпускания. Так длина гейта на BSP имеет значение. Внутренняя огибающая Plaits пингуется
  на каждой ноте и через энкодеры 10-12 двигает timbre, morph и высоту.
- Accent: уровень ноты 1.0, обычная нота - ниже на силу accent.
- Слайд: триггер не опускается, высота ползёт с glide. Новая нота без слайда: триггер опускается
  на один блок Plaits (12 сэмплов) и поднимается.
- Plaits считает блоками по 12 сэмплов; голос держит буфер из 12 и досчитывает по мере расхода.

### Смена типа

- Уход звука за 4 мс, переключение, приход за 4 мс. Состояние нот (стек, гейт) сохраняется.
- Ручки хранятся как сырые значения CC (0-127) по типу; 0xFF - не трогали, значит значение по умолчанию.
  При переходе на тип параметры сбрасываются в умолчания и применяются запомненные ручки.

### Ядра

- Ядро 1: MIDI, ударка, синт 1, микс. Ядро 0 (там живёт USB): синт 2, параллельно, кусками по 32
  сэмпла, синхронизация уведомлениями задач. Частота 240 МГц.
- На хосте и в автопилоте всё считается в одном потоке тем же кодом.

### Flash

- NVS, один blob: типы обоих синтов и сырые ручки. Пишет задача низкого приоритета после смены
  типа, если были изменения. Риск: запись во flash останавливает кэш обоих ядер. Замеряем на
  железе; если ловим underrun - пишем только когда оба синта молчат дольше 1 с.

### Архитектура

- `components/plaits/`: копия нужной части Plaits и stmlib (MIT, заголовки сохранены, правки помечены
  комментарием `acid:`), C-обёртка `acid_plaits.h`. Собирается и на хосте (C++), и в ESP-IDF.
- `acid_synth`: синт-слот `acid_slot_t` (тип, голос 303, голос Plaits, стек нот, память ручек).
  Автопилот играет слотом 0 как раньше.
- `main/`: рендер слота 1 на ядре 0, сохранение в NVS.

## Отдано на усмотрение исполнителя

- Точные кривые ручек Plaits, уровень Plaits относительно 303 (подогнать по RMS).
- Формат blob, ключи NVS.
