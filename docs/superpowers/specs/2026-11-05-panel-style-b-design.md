# Стиль панели «Б. Тёплый аналог»

Макеты: `docs/design/panel-mockups.html`, выбран вариант Б.

## Цель

Перекрасить и переодеть UI панели без смены раскладки, зон тача и числа объектов LVGL. Звук и синт не трогаем.

## Что меняется

1. **Шрифт** Barlow Condensed (OFL) вместо Montserrat. Конвертер свой, на Python (`tools/fonts/lvfont.py`,
   системный `/usr/bin/python3`: PIL с FreeType и raqm, fontTools), без npm. Выход - C-файл формата
   `lv_font_fmt_txt` (4 bpp, без сжатия, кернинг парами).
   Набор (замена кегля Montserrat):
   - 12 -> `bc_15`, 14 -> `bc_17`, 20 -> `bc_22`: полный ASCII 0x20-0x7E и `‹ › × ±`;
   - 28 -> `bc_32`, 48 -> `bc_58`: 0x20-0x5F (цифры, заглавные, знаки) и `‹ ›`.
   `LV_SYMBOL_*` (FontAwesome) заменяются глифами шрифта: LEFT -> `‹`, RIGHT -> `›`, CLOSE -> `×`, PLUS -> `+`.
   Montserrat выключается в `sdkconfig.defaults` (кроме того, что нужно самой LVGL по умолчанию).
2. **Палитра** в `panel/main/ui_priv.h`: тёплый графит (фон `#13110e`, плашки `#1d1a15`, рамки `#2b2720`), кремовый
   текст `#f1e7d0`, приглушённый `#a99f8a`, тусклый `#5f574a`. Все сырые цвета из `ui*.c` - в токены.
3. **Цвета страниц и ручек** (`pl_labels.c`: `PAGE_COLOR`, `pl_knob_color`) - тёплые «лампы» из макета.
   В `docs/controls.html` цвета страниц - тоже.
4. **Формы:** радиус карточек 14, дуга карточки 7 px, большая дуга 16 px, у карточки «светодиод» цвета страницы
   (существующая `pdot` с рамкой), подчёркивание имени страницы в шапке (новый объект один на экран - допустимо,
   проверить кучу).
5. **Чашка Петри:** палитра `petri_palette` в тёплых тонах (LUT, стоимость та же).

## Не меняется

Координаты, размеры, зоны тача, протокол, логика. Демо-трек бит в бит (синт не трогаем).

## Проверка

- Тесты конвертера: `python3 -m unittest discover -s tools/fonts` (системный python).
- Хост-тесты, сборка панели, размер шрифтов по map (ожидание: меньше ~181 КБ Montserrat).
- На плате: лог `lvgl heap` после построения всех экранов, плавность крутилки, внешний вид - глазами пользователя.
