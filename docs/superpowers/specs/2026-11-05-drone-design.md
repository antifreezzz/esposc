# Режим дрона (DRONE) под управлением страницы 9 TONAL

## Цель

Добавить режим `DRONE`, в котором оба синтезатора (`SYNTH 1` и `SYNTH 2`, а также их слои `LAYER 1` и `LAYER 2`, если они включены) непрерывно тянут опорную ноту без затухания, а высоту звучащих голосов ведёт страница `9 TONAL` как по тактовым чертам, так и в реальном времени при повороте ручек.

## Поведение в синтезаторе (`acid_tonal`, `acid_synth`, `acid_plaits`, `acid_petri`)

1. **Опорная нота и включение (`acid_synth_set_drone`)**
   - Базовая нота дрона по умолчанию: `ACID_DRONE_NOTE = 36` (C2, 65.41 Гц).
   - `acid_synth_set_drone(acid_synth_t *s, int on)`:
     - При `on = 1` выставляет `s->drone = 1` и всем слотам (синтам и слоям) ставит `v->pp.sustained = 1`. Если у синта стек нот пуст (`nheld == 0`), запускает `ACID_DRONE_NOTE` на синте и его слое; если нота уже удерживалась (переход `LIVE -> DRONE`), оставляет её опорной нотой дрона и перестраивает высоту по `9 TONAL`.
     - При `on = 0` сбрасывает `s->drone = 0`, `v->pp.sustained = 0` и плавно отпускает голоса через `acid_synth_notes_off(s)`.

2. **Удержание и смена базовой ноты от MIDI**
   - В режиме `s->drone == 1` события `ACID_MIDI_NOTE_OFF` на каналах синтов (`BASS_CH`, `SEQ2_CH`) игнорируются; `ACID_MIDI_STOP` останавливает шагатель `beat` и автобарабаны `drummer`, но не сбрасывает ноты дрона.
   - Новое событие `ACID_MIDI_NOTE_ON` на канале синта при уже звучащем дроне заменяет его базовую ноту со слайдом (`slide = 1`), без перезапуска огибающей фильтра (`fenv`). У голоса `PETRI` активный голос переносится на новую ноту и частоту через `acid_petri_move` без сброса фазы и без удара огибающей.
   - Канал ударных (`DRUM_CH`) и `GRIDS` продолжают работать штатно.

3. **Управление высотой со страницы `9 TONAL`**
   - Функция `acid_tonal_drone_note(const acid_tonal_t *t, int note)` всегда сдвигает базовую ноту на тонику `t->tonic` (`note + t->tonic`) и применяет сдвиг текущего шага `t->raw[t->step]` в выбранном ладу `t->scale` (или в полутонах при `t->scale == 0`), даже когда `t->len == 0` (`STEP LEN = OFF`).
   - Слот подчиняется `9 TONAL`, если `t->target == 0` (`BOTH`) или `t->target == idx + 1` (`S1` / `S2`).
   - Перестройка высоты (`drone_retune`) вызывается:
     - на каждой границе шага `9 TONAL` по клоку (`tonal_boundary`), когда `STEP LEN > 0`;
     - сразу при повороте любой ручки страницы `9 TONAL` (`ROOT`, `SCALE`, `TARGET`, `HELD`, `STEP 1..8`) или `TRANS` на странице синта/слоя.
   - При изменении целевой высоты слота: если `HELD == SLIDE` (`1`), высота плавно скользит со временем `GLIDE` слота (`v->gliding = 1`); иначе высота меняется скачком без перезапуска огибающих.

4. **Непрерывное возбуждение моделей Plaits**
   - В `acid_plaits_params_t` добавляется флаг `sustained`. В `acid_plaits.cc` при `pp->sustained != 0` выставляется `m.trigger_patched = false` (`TRIGGER_UNPATCHED` внутри Plaits) при сохранении `m.level_patched = true`. Все 24 модели Plaits (включая `MODAL`, `STRING`, `SWARM`, `SPEECH`, `DX7`, `CHIP`, ударные модели) переходят во встроенный режим непрерывного возбуждения, пока открыт гейт.

## Переключение на панели и автономный клок (`panel_link`, `main`)

1. **Протокол и кнопка статуса в шапке панели**
   - В `pl_proto.h`: `enum { PL_DEMO_METAL, PL_DEMO_ACID, PL_DEMO_DRONE, PL_DEMO_SONGS = PL_DEMO_DRONE };`.
   - В снимке `send_snapshot` при `s_synth->drone` поле `snap.demo` равно `PL_DEMO_DRONE`.
   - `pl_view_status` возвращает `"NO LINK"` без связи, `"DRONE"` при `m->demo == PL_DEMO_DRONE`, `"LIVE"` при `m->mode == 1`, иначе имя демо-трека (`"METAL"`, `"ACID"`).
   - `pl_view_demo_tap` разрешает тап по статусу в шапке со связью как без контроллера (`mode == 0`), так и в `LIVE` (`mode == 1`).

2. **Режимы в `main/main.c`**
   - Без BSP (`!live`): тап по статусу листает по кругу `METAL -> ACID -> DRONE -> METAL` с плавным уходом громкости 50 мс. При входе в автономный `DRONE` демо выключается (`s_demo_on = 0`), загружаются сохранённые ручки пользователя (`blob`), включается `acid_synth_set_drone(&s_synth, 1)`, подаётся `ACID_MIDI_START` и запускается внутренний клок раз в `ACID_DEMO_TICK` кусков (125 BPM), чтобы `9 TONAL` и `GRIDS` шагали по тактам без внешнего MIDI.
   - С подключённым BSP (`live`): тап по статусу сразу переключает `LIVE <-> DRONE` без перезапуска синта. Если `DRONE` был выбран на панели до подключения BSP, при подключении контроллера режим `DRONE` сохраняется.
