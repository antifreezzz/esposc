esposc: корпус, внутренняя компоновка, пины

Чертёж в миллиметрах, всё рисуется из параметров внизу страницы. Размеры платы взяты из чертежа Espressif (62.74 x 25.40), размеры хаба и свистка - оценка (поля с жёлтой рамкой): сними штангенциркулем, впиши, чертёж перестроится.

Главное правило корпуса. Разъём USB (OTG) платы наружу не выходит вообще: он внутри, коротким угловым кабелем в хаб. Наружу выведен только COM. Так «никогда не втыкать USB в ПК» обеспечено механикой, а не памятью.

Вид со стороны компонентов, антенна сверху. Порядок пинов по документации Espressif v1.1. У N8R2 PSRAM quad, поэтому GPIO35-37 свободны (на N8R8 они заняты octal PSRAM). Какой из двух разъёмов COM, а какой USB - сверь по шелкографии своей платы, на чертеже COM справа.

Бюджет. Ядро 0 на стресс-песне занято ~440 из 666 мкс на кусок, ядро 1 ~1630 из 2000. Экран отдавать задаче низкого приоритета на ядре 0, рисовать только изменившиеся области, SPI через DMA из буфера строк во внутренней SRAM (не PSRAM: там дилэй и статтер, шина общая). LVGL не брать: дорого и не нужно для пары цифр. Новое в этой задаче мерить стендом build-stress, как всё остальное.

Пины под SPI выбраны на J1 подряд (GPIO9-14): это родные пины FSPI через IOMUX, 80 МГц без матрицы, и весь шлейф уходит с одной гребёнки. Под OLED - GPIO8 и GPIO18, тоже J1.
